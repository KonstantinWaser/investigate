# investigate

A personal research desk: you hand it things to look into, and it returns cited reports placed in the context of what you are working on.

## Language

### Input

**Inbox**:
A place Items arrive from: the quick-capture box, an Instagram Collection, or a YouTube playlist.
_Avoid_: Source, feed, channel

**Item**:
One thing to look into: free text, one or more URLs, a file, an image, a reel or a video.
_Avoid_: Entry, post, query

### Work

**Run**:
One execution on an Item, of a given Kind and Depth.
_Avoid_: Job, task, research

**Investigation**:
A Run that researches an open topic in depth.
_Avoid_: Deep research, search

**Fact-check**:
A Run that extracts the claims an Item makes and gives each one a Verdict.
_Avoid_: Verification, check

**Depth**:
How far a Run goes: quick, standard or deep.
_Avoid_: Mode, level

**Verdict**:
The judgement on one claim: Confirmed, Partly true, Outdated, Unverified or Wrong.
_Avoid_: Rating, score

**Follow-up**:
A question asked on a finished Report that continues the same Run.
_Avoid_: Reply, chat

### Output

**Report**:
The HTML page a Run produces.
_Avoid_: Overview, digest, result

**Citation**:
A piece of evidence a Report links to.
_Avoid_: Source, reference

**Context**:
The user's own files describing what they are working on, which a Report relates its findings to.
_Avoid_: Profile, projects, memory

**History**:
The list of past Runs and their Reports.
_Avoid_: Archive, log
